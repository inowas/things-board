How to use the mWater Sync widget

This widget copies data from mWater into ThingsBoard and keeps it up to date automatically — no manual exports. Below: how to get the export link, what the buttons do, and how it all works.

1. Get the mWater export link

  1. In mWater, open the menu Manage → Integrations, then click + New Export Integration (top right).
  2. Set a Name of Integration. For full history, leave Maximum Rows empty (empty = no limit). Use Add Column to include the columns you need: the date, the point column (if there are several measurement points), and the measured parameters.
  3. At the bottom, in URL Preview, switch the format to JSON and copy the link. This is the link you paste into the widget.
The link should open in a browser and show a JSON array (it starts with a square bracket). The format must be JSON, not CSV.

2. Widget fields and buttons

  • Single device / Split by point — the mode. Single device: all rows go to one device (fill in Device name). Split by point: data is split per measurement point — each point into its own device (fill in Point column = the name of the column holding the point name, e.g. Name; the Prefix field is optional).
  • mWater JSON export URL — the link from step 1.
  • Date column — the name of the column holding the date (e.g. Date, Time, or submitted on).
  • sync — the sync checkbox. On: the dataset keeps updating. Turn it off once the history is loaded, so it is not re-uploaded on every run.
  • Add dataset — adds a row to the list (on screen only for now).
  • Save — writes the list. Changes take effect only after Save.
  • Reload — re-reads the saved list (discards unsaved edits).

3. How it works under the hood

  • The dataset list is stored as a datasets attribute on the mWater config device. The widget simply edits this attribute.
  • A dedicated rule chain, mWater Sync (auto-create), reads the list on a timer and transfers the data.
  • The update frequency is set by the Tick node ("Generation frequency in seconds"). For static history, once a day (86400) is plenty. This node's originator is the mWater config device.
  • Devices are created automatically. If a point has no device yet, the chain creates one (type mWater point) — no need to create them by hand.
  • The access token is taken automatically from your ThingsBoard session and refreshes itself — nothing to copy.
  • Administrator rights (tenant admin) are required, otherwise the widget cannot read or write the list and data.
The widget itself lives in Resources → Widgets library → Widgets bundles → Custom tools — from there it can be added to any dashboard.
